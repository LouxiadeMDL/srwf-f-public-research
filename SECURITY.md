# Security and accidental disclosure

Do not post secrets, private paths, game data or exploit payloads in issues. Report a concern using GitHub's private vulnerability reporting if enabled; otherwise open a minimal issue requesting a private contact channel without sensitive details. No private reporting channel or response time is promised by this file.

The included tools are offline utilities. Treat all research inputs as untrusted, retain original files unchanged, and review tools before running them. No legacy executable is required.
