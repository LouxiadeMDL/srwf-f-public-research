# Web cross-check sources

These sources were used only to normalize scenario identifiers, names, page roles and game facts around the 44 QA records. They do not replace the private SS35 scan transcription.

## Japanese

- [スーパーロボット大戦Ｆ完結編攻略データベース](https://srwffinal.tuzigiri.com/) — scenario numbering/titles and Saturn-oriented game-data cross-check.
- [隠しパイロット](https://srwffinal.tuzigiri.com/hide.html) — hidden/recruitment conditions.
- [隠しユニット](https://srwffinal.tuzigiri.com/hideunit.html) — hidden/acquisition unit conditions.
- [SRW Wiki: 隠し要素/F・F完結編](https://srw.wiki.cre.jp/wiki/隠し要素/F・F完結編) — secondary compilation; retained as a separate source when fine conditions disagree.
- Stage-detail pages from Tuzigiri were used for the flagged scenario pages, including SCENE01, 02, 09, 12, 16, 17, 25, 27, 28, 39, 41, 42, 46, 48, 50, 53 and 54.

## Chinese

- [RitaPlay: 超級機器人大戰F完結篇](https://ritaplay.com/SrwFF/index.php) — Traditional-Chinese index/database.
- [RitaPlay: 詳細攻略](https://ritaplay.com/SrwFF/Story.php) — stage index and selected stage-detail cross-check.
- [RitaPlay: 人物資料](https://ritaplay.com/SrwFF/Pilot.php) — name/stat-schema cross-check.
- [RitaPlay: 機體資料](https://ritaplay.com/SrwFF/Unit_Status.php?key_type=原創系列) — unit/system naming cross-check.
- [RitaPlay: 敵機資料](https://ritaplay.com/SrwFF/EnemyUnit_Status.php?key_type=原創系列) — enemy-unit naming/stat-schema cross-check.
- Bilibili community hidden-element guide was used as secondary corroboration only.

## Platform rule

RitaPlay labels its F Final material as SS/PS. Therefore, when a value could differ by platform, mixed-platform numeric data is never used to overwrite an SS35 scan cell. Exact SS-specific table cells remain source-image authoritative.
