Limited native pathways included Chapter 1-end ordinary-save cold load, Chapter 2 S/Ex-S active and counterattack sequences (four distinct recorded battle paths), and a later in-game native Save → fresh Continue. A VDP texture/palette-consumer report and exact media/resource rebuild records were retained separately. Four battle videos were silent, and are not included here.

## R5 opaque-black outline restoration / 地图图标轮廓

The old PNG→RGB import treated **opaque black** as palette-transparent index 0 and erased valid unit outlines. R5 restored **423** black pixels across the four **16×16** icons (**111/94/129/89**). All other colors, 128-byte palette, other **508** icon tiles and rendering code were retained. The reported R4→R5 media delta affected only **three raw sectors**: **20, 101612, 101613**, belonging to the KOM data/directory. Other gameplay/animation resources and Track2/Track3 were unchanged.

Four independent **Linux Ymir + native BIOS** cold-read comparisons used the same ordinary cards for normal and cruise forms. Only the expected outline pixels differed in matched native frame-buffer views, with preserved loaded components and ordinary-card checks. This R5 test covers **map icons and save compatibility**, not a repeat of the R4 combat scenarios.

**R5 Track1 SHA-256:** `b7bb37ffe7f4b718ca4bba32e47df0db68d26b7ab1dbe5793b6706cb2678b4ef`.
