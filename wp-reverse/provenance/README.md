# Provenance

This directory is a new public-safe consolidation layer. It does not bulk-copy private databases or game-derived payloads.

Historical dataset identities and counts come from the public 2026-09-22 handoff catalog and previously verified local audit metadata. WP-B claims are rewritten from the current read-only reverse-engineering audit outputs; old IDs are retained only as provenance.

The public SQLite is reconstructed from the CSV/JSON files in this directory and contains no ROM/BIN bytes, font images, dialogue dumps, save images or legacy executable code.
