# Contributing

Small corrections and independently checkable observations are welcome. Identify Saturn or PlayStation, F or F Final, exact variant, input representation/hash, method and uncertainty. Explain whether evidence is a report, byte observation, static analysis or runtime trace.

Submit only original work or material with clear redistribution permission, under the repository's MIT terms. Attribute sources and keep quoted material minimal. Do not attach game images, resource dumps, fonts, dialogue, patches containing game bytes, proprietary software, private messages or credentials. Prefer synthetic examples and factual descriptions. Unknown rights mean omit the file.

Run the checks in docs/reproduce.md. Review the exact diff and regenerate the allowlist only after review. A test pass does not promote a research claim or authorize a new research stage.
